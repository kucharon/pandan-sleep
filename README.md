# 熊猫睡眠 · 助眠推荐页交互原型（最终版）

移动端睡眠 App 高保真交互原型：纯 HTML / CSS / JavaScript，无框架、无网络依赖。
本版本由对比方案中选定的「对比版 3」整理而来，包含完整的助眠推荐页、首页、搜索、监测助眠、系列课介绍等页面。

## 预览

- **单文件离线版**：`dist/panda-sleep-prototype.html`（约 20.6MB，图片全部内联，双击即可打开）
- 源码运行：

```bash
python3 -m http.server 8000

# 浏览器访问 http://localhost:8000/
```

## 功能

- 首页：今日专属推荐、热门榜单（2 页 × 5）、我的专属计划等
- 助眠推荐页：最近上新（5 个轮播）、最近/收藏、为你推荐（两步筛选 + 滑动切题 + 1s 搜索动效）、精选音频、精选系列课、听你所需
- 系列课介绍页：SVIP/功效/类型标签、人物在看、课程内容列表
- 搜索页：上新榜 / 热门榜（各 5 条）、搜索发现
- 监测助眠：今日专属推荐卡片（大图胶囊样式）、最近/收藏、为你推荐、听你所需
- 「更多」页面：大类型图标 + 小类型名称 + 双列音频卡片
- 介绍页、播放器、收藏/历史、收藏页等
